Scenario-based learning Branching simulation Behavioral gap Claude API ADDIE 45 min

Features a branching simulation with three decision paths, composite manager personas grounded in real avoidance patterns, and Claude API integration for personalised AI coaching feedback. Built in vanilla HTML/CSS/JS using Cursor and Claude Code.
